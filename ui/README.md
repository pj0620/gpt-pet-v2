# GPTPet Management Portal (`ui/`)

React 19 + Vite 8 + Tailwind 4 + shadcn/ui (Base UI), managed with Bun. One page, four panels:
goals queue, camera view, top view, events log. See the repo README for the API it talks to.

```bash
bun install
bun run dev              # http://localhost:5173, proxies /api to `gpt-pet serve` on :8080
bun run build            # ui/dist, served by the pet server in production
bun run lint             # Biome
bun run typecheck
bun run test             # Vitest, pure functions only
bun run test:e2e         # Playwright @smoke (Vite only, pet offline)
bun run test:e2e:live    # Playwright @live: starts `gpt-pet serve` + simulator, real Gemini
```

`src/components/ui/` is generated by `bunx --bun shadcn@latest add <component>`; do not hand-edit.
